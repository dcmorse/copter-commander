This is the infamous 42944 bug in the Linux `ldd` linker.

http://www.debian.org/Bugs/db/42/42944.html

  "Basically, it involves having a shared library that calls
   pthread library functions, and a program that uses the
   shared library but isn`t linked against libpthread itself."

The work-around is to link the pthreads library into
your program explicitly rather than relying on Mesa
to pull it in.

This bug has been around long enough to make it into
a Linux fortune cookie!

  "Stopping Apache webserver...sleeping...starting again...
   apache: dl-version.c:189: _dl_check_map_versions: Assertion
   `needed != ((void *)0)` failed
   noooooooooooooooooooooooooooo
        -- netgod on #Debian at LISC"

Enjoy!
