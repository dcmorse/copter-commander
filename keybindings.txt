COPTER CONTROL

(place left hand on shift-z-x-c, right hand on mouse)

mouse-left           turn around
shift, mouse-middle  fire gun
z, mouse-right       drop bomb
x                    launch missle
c                    launch rocket
space                parachute men (when on board)
x                    construct hut (grounded cargo copter)
c                    construct gun (grounded cargo copter)
mouse-move           fly to mouse cursor
__________________________________________________
UNIT PURCHASE

t                    order tank
m                    order man
e                    order engineer
a                    order anti-aircraft truck
v                    order demolition van
h                    order fancy copter
n                    next copter type (gunship, cargo, mech)
__________________________________________________
MECH CONTROL

mouse-left           fire plasma gun
mouse-move           aim gun at mouse cursor
z, left-arrow        run left
x, up-arrow          jump jets
c, right-arrow       run right

___________________________________________________
COMPUTER PLAYER MANAGEMENT

C-l                  Add left side computer player
C-r                  Add right side computer player
C-Sh-l               Remove left side computer player
C-Sh-r               Romove right side computer player
__________________________________________________
MISCELLANEOUS

return               talk mode (return sends)

C-b                  toggle alpha blending on/off

escape               ungrab mouse
tab                  regrab mouse
